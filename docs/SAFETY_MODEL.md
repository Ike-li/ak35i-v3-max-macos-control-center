# 安全模型

这个项目控制的是带有私有 HID 接口的键盘。错误报文可能改变板载配置、导致不可预期的键位行为，或破坏用户无法导出的屏幕内容。

因此项目采用以下边界：

1. **白名单写入**：只有经过真机验证的屏幕时钟序列可以写入。
2. **不枚举 opcode**：不会为寻找功能而向设备穷举未知命令。
3. **先恢复能力，后开放功能**：涉及配置的功能必须先有读取或明确的可恢复路径。
4. **不处理固件**：固件升级、DFU、恢复出厂永远不在范围内。
5. **USB 优先**：蓝牙与 2.4G 的配置行为没有得到验证时，界面会明确显示不支持。
6. **最小数据**：不上传数据，不保存设备序列号，不包含厂商二进制资源。

这意味着部分页面会显示“等待抓包”而不是提供看似可用的按钮。该设计优先保护设备状态与用户数据。
