# AK35I V3 Max Windows 抓包工作单

目标是为每个功能获得可重放的 V3 Max HID 证据，而不是通过猜测写入报文。

## 准备

1. 使用项目 `artifacts/vendor/` 中已留存的 `AJAZZ_AK35I_MAX_V3_Tripe_mode_RGB_with_screen_keyboard_driver_V1.0.0.zip`。来源、SHA-256 与选择边界见 [驱动溯源记录](DRIVER_PROVENANCE.md)；不要使用单模 V3、V3 Pro 或 V4 驱动。
2. 在实体 Windows 电脑连接键盘，拨到 USB 模式；安装 USBPcap 和 Wireshark。
3. 记录键盘固件/驱动版本、USB VID:PID、接口号和抓包开始时间。
4. 每次录制只变更一个设置。录制前后都截图键盘屏幕或灯效，并把设置恢复为基线。

## 每项功能的录制顺序

对下面每一项生成一个独立 `.pcapng`：

1. 打开驱动，等待稳定 5 秒，开始抓包。
2. 执行一次操作并点击保存/应用。
3. 等待 5 秒，停止抓包；记录屏幕或灯效结果。
4. 重新开始抓包，把同一项恢复基线；保存恢复抓包。

优先顺序：

1. 电量读取、睡眠时间、屏幕语言和时钟同步。
2. RGB：模式、颜色、亮度、速度、方向，以及三组游戏灯效。
3. 屏幕：先静态纯色/测试图，再单帧图片，最后短 GIF。
4. 一个普通改键、一个 Fn 层改键、一个最短宏及其删除。

## 每个功能的交付物

- 基线抓包与单项变更抓包。
- UI 操作的屏幕录像或准确步骤。
- 驱动文件名、SHA-256、版本与条码后六位。
- 设置前后效果照片。
- 恢复基线的抓包。

没有“读取当前配置 + 可回滚”的证据时，macOS 控制中心不会启用对应写入功能。固件升级、DFU 和恢复出厂始终不在范围内。
