# 故障排查

## macOS 阻止首次打开

当前预览 DMG 未经过 Apple 公证。请在 Finder 中按住 Control 点击应用，选择“打开”，再确认一次。不要关闭系统安全机制或运行来源不明的替代程序。

## 显示“未发现 USB 有线控制接口”

1. 使用数据线直连键盘；不要通过仅供电的线缆。
2. 将键盘切到 USB 模式，而不是蓝牙或 2.4G。
3. 在“概览”页点击“刷新设备”。
4. 确认设备是已验证的 `0C45:8009`，再尝试校时。

蓝牙和 2.4G 的控制协议未在本项目中承诺支持，界面不会伪造成功。

## 点击同步后失败

- 先确认“时钟”页的协议状态为“已验证”。
- 关闭其他可能独占键盘 HID 接口的控制程序。
- 重新插拔数据线、刷新设备，再以 `--dry-run` 预检。
- 若仍失败，提交 issue 时提供 macOS 版本、应用版本、VID:PID、错误码和脱敏日志。

## 时间同步后不保留

请在 USB 模式校时后切换到目标连接模式验证。若时间不能保留，请提交复现步骤；不要自行发送未知 HID 命令或尝试固件升级。
