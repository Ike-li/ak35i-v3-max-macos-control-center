# 故障排查

## macOS 阻止首次打开

发布包没有 Apple 开发者签名，也没有经过公证。先在提示框点“完成”，再打开“系统设置 › 隐私与安全性”，在“安全性”部分点 AK35i Control Center 旁边的“仍要打开”，输入登录密码确认。macOS 14 及更早版本也可以在 Finder 中按住 Control 点按应用，选择“打开”。

不要为此关闭 Gatekeeper，也不要运行来路不明的替代程序或命令。

## 概览页显示未连接

1. **USB**：用数据线直连，不要用只能充电的线；键盘拨到 USB 档。
2. **2.4G**：接收器插在 Mac 上，键盘拨到 2.4G 档；键盘休眠时不应答，先按一下任意键。
3. **蓝牙**：在系统的蓝牙设置里连接 `AK35i BT-1`（或 2、3）。
4. 回到“概览”页点“刷新设备”。

## 写入失败或没有效果

- 关闭其他可能占用键盘的控制程序。
- 2.4G 下先按一下键盘唤醒，再重试。
- 蓝牙下键盘不接受设置命令。改用接收器或数据线写入，切回蓝牙后设置仍然保留。
- 重新插拔或切换一次连接方式，刷新后再试。仍然失败时，请提交 issue，写明 macOS 版本、应用版本、连接方式和错误信息。

## 音乐律动没有反应

- 需要 macOS 14.2 或更高版本，并在“系统设置 › 隐私与安全性 › 屏幕与系统录音”里允许本应用录制系统音频。
- 背景选“无”且没有声音时，程序不发送画面，键盘显示它自己的灯效。这与 Windows 驱动的做法相同。
- 整块键盘一直全亮：Windows 驱动原版的振幅很灵敏，正常音量下所有频段都会顶满。把“振幅”调低就能看到起伏。

## 更新后又要求授权

发布包使用 ad-hoc 签名，每个版本的签名都不同，macOS 可能把新版本当作新的应用，重新请求蓝牙或系统录音权限。再次允许即可。
