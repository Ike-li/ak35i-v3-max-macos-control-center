# AJAZZ AK35i V3 Max manual (English entry point)

Applicable model: **AK35i V3 Max tri-mode keyboard with display** — USB wired, 2.4G wireless, Bluetooth 5.1, 104 keys, and a metal knob.

Read the complete English manual at [Manuals+](https://manuals.plus/ajazz/ak35i-v3-max-bt-tripe-mode-mechanical-keyboard-manual). If that page is unavailable, use the [PDF mirror and model record](https://device.report/m/2b64f41f2a4ea9f90fe7f2a06bbf1a5ff837da3af10d79e2a3dd58fa5139859a).

## Connection and switching

| Function | Operation |
|---|---|
| Bluetooth channel 1 / pairing | Press `Fn+Q` to switch; hold for about three seconds to pair (`AK35i BT-1`) |
| Bluetooth channel 2 / pairing | Press `Fn+W` to switch; hold for about three seconds to pair (`AK35i BT-2`) |
| Bluetooth channel 3 / pairing | Press `Fn+E` to switch; hold for about three seconds to pair (`AK35i BT-3`) |
| Re-pair the 2.4G receiver | Switch to 2.4G and hold `Fn+R` for about three seconds |
| USB wired mode | Put the hardware switch in the centre USB position and connect the Type-C cable |
| macOS / Windows layout | Use the physical Mac / Win switch on the keyboard |

## Display and knob

| Function | Operation |
|---|---|
| Enter / exit display settings | `Fn+press knob` |
| Navigate / confirm | Turn the knob to choose; press it to confirm |
| Animation / main display | `Fn+PrtSc` |
| Turn the display on or off | `Fn+ScrLk` |
| Chinese / English display language | `Fn+C` / `Fn+V` |
| Volume / mute | Turn right / left; press to mute |

The main display includes date, time, battery, Mac/Win, USB/2.4G/Bluetooth status, and Win/Caps/Num lock indicators.

## Lighting and caution

- `Fn+\\|` cycles the 20 lighting effects; `Fn+Up/Down` adjusts brightness; `Fn+-/=` adjusts speed; `Fn+X` toggles lighting.
- Holding `Fn+Space` for roughly 3–5 seconds performs a factory reset. Do not use it unless you intentionally want to clear onboard configuration.
- These are hardware shortcuts only. They do not prove that the macOS app can write the corresponding function over Bluetooth. This project currently verifies **USB wired clock sync** only.
