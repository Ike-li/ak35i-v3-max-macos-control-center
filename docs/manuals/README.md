# AK35i V3 Max manuals

This directory provides bilingual, repository-local entry points for the **AK35i V3 Max tri-mode keyboard with display**. They identify the correct model, link to the source manual, and summarize only the controls relevant to this project.

The original manufacturer manual is not mirrored here. This keeps the public repository from redistributing a third-party PDF whose publication licence is not stated. Use the source links below for the complete document.

| Language | Repository entry point | Complete source manual |
|---|---|---|
| 简体中文 | [中文说明书入口](AK35I_V3_MAX.zh-CN.md) | [Manuals+ 中文版](https://zh-cn.manuals.plus/ajazz/ak35i-v3-max-bt-tripe-mode-mechanical-keyboard-manual) |
| English | [English manual entry point](AK35I_V3_MAX.en.md) | [Manuals+ English edition](https://manuals.plus/ajazz/ak35i-v3-max-bt-tripe-mode-mechanical-keyboard-manual) |

An additional [PDF mirror and model record](https://device.report/m/2b64f41f2a4ea9f90fe7f2a06bbf1a5ff837da3af10d79e2a3dd58fa5139859a) identifies the document as `AK35IV3` / `2AY3H-AK35IV3`.

> These are reference links, not evidence that every shortcut is controllable by this macOS project. Current verified software writes remain limited to USB screen-clock sync.
