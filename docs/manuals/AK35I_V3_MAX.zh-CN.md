# AJAZZ AK35i V3 Max 使用说明（中文入口）

适用型号：**AK35i V3 Max 三模带屏版**，USB 有线 + 2.4G + 蓝牙 5.1，104 键与金属旋钮。

完整中文说明书请访问：[Manuals+ 中文版](https://zh-cn.manuals.plus/ajazz/ak35i-v3-max-bt-tripe-mode-mechanical-keyboard-manual)。若网页失效，可使用 [PDF 镜像与型号记录](https://device.report/m/2b64f41f2a4ea9f90fe7f2a06bbf1a5ff837da3af10d79e2a3dd58fa5139859a)。

## 连接与切换

| 功能 | 操作 |
|---|---|
| 蓝牙通道 1 / 配对 | 短按 `Fn+Q` 切换；长按约 3 秒配对（设备名 `AK35i BT-1`） |
| 蓝牙通道 2 / 配对 | 短按 `Fn+W` 切换；长按约 3 秒配对（`AK35i BT-2`） |
| 蓝牙通道 3 / 配对 | 短按 `Fn+E` 切换；长按约 3 秒配对（`AK35i BT-3`） |
| 2.4G 重新配对 | 切到 2.4G 档；长按 `Fn+R` 约 3 秒 |
| USB 有线 | 模式开关置于 USB 中间档，再连接 Type-C 数据线 |
| Mac / Windows 布局 | 使用键盘底部的 Mac / Win 物理开关 |

## 屏幕与旋钮

| 功能 | 操作 |
|---|---|
| 进入 / 退出屏幕设置 | `Fn+按下旋钮` |
| 在设置中选择 / 确认 | 转动旋钮选择，按下旋钮确认 |
| 屏幕动画 / 主页面 | `Fn+PrtSc` |
| 开关屏幕 | `Fn+ScrLk` |
| 屏幕中文 / 英文 | `Fn+C` / `Fn+V` |
| 音量 / 静音 | 旋钮右转 / 左转；按下静音 |

主页面会显示日期、时间、电量、Mac/Win、USB/2.4G/蓝牙状态，以及 Win、Caps 和 Num 锁定状态。

## 灯光与注意事项

- `Fn+\\|`：循环 20 种灯效；`Fn+↑/↓`：亮度；`Fn+-/=`：速度；`Fn+X`：灯光开关。
- `Fn+Space` 长按约 3–5 秒会恢复出厂设置；除非你明确需要清除板载配置，否则不要按。
- 这份说明书是硬件快捷键参考，并不表示 macOS 应用能通过蓝牙写入同一功能。当前本项目只验证了 **USB 有线校时**。
