# 功能与协议状态

此参考页说明每项功能的可用状态，不代表厂商公开规格。

| 功能 | 状态 | 依据与边界 |
|---|---|---|
| USB 设备发现 | 已验证 | VID:PID `0C45:8009`；仅匹配厂商 HID collection，避免访问普通键盘输入接口。 |
| 屏幕时钟同步 | 已验证 | 64-byte Feature 载荷；UTC+8 与 Mac 当前时区均可选。 |
| 屏幕数据通道发现 | 已验证 | `0xFF68:0x0061`，Output 4 KiB；不代表已验证图片/GIF 格式。 |
| 电量读取 | 锁定 | 读取命令与语义尚未通过 V3 Max 抓包验证。 |
| 基础灯效 | 实验性 | `04 13` 序列：20 种模式及亮度、速度、方向、颜色。模式 1 静态色已在 macOS 实机验证（设备确认、效果正确、重连后保留），模式 16 川流不息目测正常；亮度 0 为熄灭、速度 0 最慢 5 最快、方向 0 与 1 互为反向已经实测确认。其余模式沿用同一命令，模式号和参数取值来自 Windows 驱动静态分析，效果和方向 2/3 待确认。在控制中心“灯光”页或 CLI `ak35i light set` 写入，可用 `Fn+\\|` 等快捷键恢复。 |
| 自定义单键灯光 | 实验性 | `04 23` 写入、`04 F5` 读回。已在 macOS 实机验证（设备确认、读回一致、目测正确、重连后保留）。写入前切到自定义模式 `0x80`，读取已保存颜色并合并，写后读回核对。读回每通道约 6 位（`FF` 读回 `FC`）。在控制中心“单键灯光”页或 CLI `ak35i keys set` 写入。 |
| 系统设置 | 实验性 | `04 17` 整帧写入：禁用 Win / Alt+Tab / Alt+F4、Fn 开关、休眠时间、按键响应档位。用按键记录在 macOS 实机确认：Win 档下禁用 Alt+Tab、禁用 Alt+F4 生效，写 0 可解除；只开禁用 Win 不生效，与禁用 Alt+F4 同时开启才生效（固件行为，原因不明）；Mac 档下禁用 Win 不拦截。拔插后是否保留未验证。休眠、响应时间、Fn 开关按静态逆向发送，效果未确认。键盘不提供读取，每次写入覆盖全部六项；`ak35i system set --apply` 不带参数写回驱动默认值。在控制中心“系统设置”页或 CLI `ak35i system set` 写入。 |
| 实时灯效、音乐律动 | 实验性 | 由电脑逐帧推送 `04 20`（8 片逐键颜色）加 `04 02`，键盘不保存。已在 macOS 实机确认：推流期间全键显示推送的颜色，停止后立即恢复原灯效；约 12–15 帧/秒，未出现跳帧。效果（纯色、呼吸、彩虹波浪、繁星、音乐律动）由本项目设计，与 Windows 驱动 `mui.dll` 中的同名效果不同。音乐律动用 Core Audio 采集系统正在播放的声音（macOS 14.2+，需系统录音权限），16 个频段显示为音量柱。在控制中心“实时灯效”页或 CLI `ak35i live` 使用，离开页面或 Ctrl+C 即停止。驱动的“用户灯光”即上面的自定义单键灯光。 |
| 图片/GIF 上传 | 锁定 | 传输通道已见，但编码、提交序列和回滚均未验证。 |
| 板载改键 / Fn 层 | 实验性 | `04 11`（普通层）/ `04 27`（Fn 层）整层写入，每键 4 字节记录。已在 macOS 实机用按键记录确认：普通层 CapsLock→Esc 生效且拔插后保留，Fn 层 F1→静音生效且不影响普通层 F1，两层写回默认后恢复原行为。支持普通键、修饰键组合、单个修饰键、禁用、7 个媒体键和 7 个鼠标动作；宏键、多键、打开程序/网址/发送文字未开放。键盘不提供读取，每次写入整层，未列出的键恢复默认；`ak35i keymap reset --apply` 写回两层默认（与驱动“重置键盘”相同）。在控制中心“改键”页或 CLI `ak35i keymap set` 写入。 |
| 宏 | 实验性 | `04 19` / `04 15` 上传整张宏表（最多 100 个，事件数加宏数不超过 337）。已在 macOS 实机用按键记录确认：两个宏绑定到 F12、F11 后按设置播放（单次和重复 3 次，延时与设置一致），拔插后保留，清空宏并恢复改键后复原。支持按键按下/松开、组合、鼠标左中右键和等待时间；播放方式支持一次、N 次、再按停止、按住重复（后两种未实机验证），驱动的“点按播放”未开放。宏要在改键里绑定为 `macro:N` 才会播放。键盘不提供读取，每次写入替换全部宏；`ak35i macro clear --apply` 清空。在控制中心“宏”页或 CLI `ak35i macro set` 写入。 |
| 蓝牙 / 2.4G 控制 | 不承诺 | 当前发布仅支持 USB 有线控制。 |

解锁一个功能需要四类证据：单项操作对应的报文、设备应答、断线重连后的持久化，以及可恢复基线。证据可以来自 Windows 抓包，也可以来自 macOS 实机试验，前提是写错后有可恢复路径：键盘快捷键、读回后写回，或已知的默认值。静态逆向只能缩小范围，不能替代真机验证。详细记录见 [静态逆向记录](STATIC_REVERSING.md)。
