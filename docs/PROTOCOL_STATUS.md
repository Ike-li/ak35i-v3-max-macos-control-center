# 功能与协议状态

此参考页说明每项功能的可用状态，不代表厂商公开规格。

| 功能 | 状态 | 依据与边界 |
|---|---|---|
| USB 设备发现 | 已验证 | VID:PID `0C45:8009`；仅匹配厂商 HID collection，避免访问普通键盘输入接口。 |
| 屏幕时钟同步 | 已验证 | 64-byte Feature 载荷；UTC+8 与 Mac 当前时区均可选。2.4G 下经接收器发一包 `0C`（实验性），已实机验证。 |
| 屏幕数据通道发现 | 已验证 | `0xFF68:0x0061`，Output 4 KiB；不代表已验证图片/GIF 格式。 |
| 电量读取 | 实验性（只读） | 经 2.4G 接收器或蓝牙读取。蓝牙下读标准电池服务（`180F` / `2A19`），已实机读到 94%。2.4G 下向接收器的 `0xFF60:0x61` 接口（32 字节）发 `20 01`，应答 `20 01 00` 后的字节 3 为百分比，与 Windows 驱动相同。已在 macOS 实机读到 92%–99%，屏幕电量图标为满格。接收器在 Mac 上报为 `05AC:024F`“2.4G Dongle”，不是驱动配置里的 `0C45:FDFD`。有线 USB 下键盘不提供电量：驱动不读，固件 V1.17 的 USB 命令也不回电量（静态分析）。在控制中心“电量”页或 CLI `ak35i battery` 读取。 |
| 基础灯效 | 实验性 | `04 13` 序列：20 种模式及亮度、速度、方向、颜色。模式 1 静态色已在 macOS 实机验证（设备确认、效果正确、重连后保留），模式 16 川流不息目测正常；亮度 0 为熄灭、速度 0 最慢 5 最快、方向 0 与 1 互为反向已经实测确认。其余模式沿用同一命令，模式号和参数取值来自 Windows 驱动静态分析，效果和方向 2/3 待确认。在控制中心“灯光”页或 CLI `ak35i light set` 写入，可用 `Fn+\\|` 等快捷键恢复。 |
| 自定义单键灯光 | 实验性 | `04 23` 写入、`04 F5` 读回。已在 macOS 实机验证（设备确认、读回一致、目测正确、重连后保留）。写入前切到自定义模式 `0x80`，读取已保存颜色并合并，写后读回核对。读回每通道约 6 位（`FF` 读回 `FC`）。在控制中心“单键灯光”页或 CLI `ak35i keys set` 写入。 |
| 系统设置 | 实验性 | `04 17` 整帧写入：禁用 Win / Alt+Tab / Alt+F4、Fn 开关、休眠时间、按键响应档位。用按键记录在 macOS 实机确认：Win 档下禁用 Alt+Tab、禁用 Alt+F4 生效，写 0 可解除；只开禁用 Win 不生效，与禁用 Alt+F4 同时开启才生效（固件行为，原因不明）；Mac 档下禁用 Win 不拦截。拔插后是否保留未验证。休眠、响应时间、Fn 开关按静态逆向发送，效果未确认。键盘不提供读取，每次写入覆盖全部六项；`ak35i system set --apply` 不带参数写回驱动默认值。在控制中心“系统设置”页或 CLI `ak35i system set` 写入。 |
| 实时灯效、音乐律动 | 实验性 | 由电脑逐帧推送 `04 20`（8 片逐键颜色）加 `04 02`，键盘不保存。已在 macOS 实机确认：推流期间全键显示推送的颜色，停止后立即恢复原灯效；约 12–15 帧/秒，未出现跳帧。效果（纯色、呼吸、彩虹波浪、繁星、音乐律动）由本项目设计，与 Windows 驱动 `mui.dll` 中的同名效果不同。音乐律动用 Core Audio 采集系统正在播放的声音（macOS 14.2+，需系统录音权限），16 个频段显示为音量柱。在控制中心“实时灯效”页或 CLI `ak35i live` 使用，离开页面或 Ctrl+C 即停止。驱动的“用户灯光”即上面的自定义单键灯光。 |
| 屏幕 GIF 页上传 | 实验性 | `04 18`、`04 72`（槽位 1、块数）后，在 `0xFF68` 接口逐块写 4096 字节 Output 报告，再发 `04 02`。已在 macOS 实机上传单帧测试图：开始与保存命令都收到确认，16 块全部收到键盘回复 `01 5A 02`，上传后屏幕立即显示测试图，方向和颜色正确；拔插后上电仍播放出厂开机动画，随后回到原来的界面，不再显示测试图。拔插后按 Fn+PrtSc 仍显示测试图（说明书写明 Fn+PrtSc 打开动画、再按返回主页面），确认断电后保留。按固件分析，上传写外置闪存 `0x950000`（GIF 页），开机动画在 `0x340000`。图片缩放到 240×135、RGB565，GIF 最多 141 帧，延时超过 510 ms 时截为 510 ms。键盘不提供读取，GIF 页原内容无法恢复。多帧 GIF 尚未实机验证。在控制中心“屏幕”页或 CLI `ak35i screen set` 上传。 |
| 板载改键 / Fn 层 | 实验性 | `04 11`（普通层）/ `04 27`（Fn 层）整层写入，每键 4 字节记录。已在 macOS 实机用按键记录确认：普通层 CapsLock→Esc 生效且拔插后保留，Fn 层 F1→静音生效且不影响普通层 F1，两层写回默认后恢复原行为。支持普通键、修饰键组合、单个修饰键、禁用、7 个媒体键和 7 个鼠标动作；宏键、多键、打开程序/网址/发送文字未开放。键盘不提供读取，每次写入整层，未列出的键恢复默认；`ak35i keymap reset --apply` 写回两层默认（与驱动“重置键盘”相同）。在控制中心“改键”页或 CLI `ak35i keymap set` 写入。 |
| 宏 | 实验性 | `04 19` / `04 15` 上传整张宏表（最多 100 个，事件数加宏数不超过 337）。已在 macOS 实机用按键记录确认：两个宏绑定到 F12、F11 后按设置播放（单次和重复 3 次，延时与设置一致），拔插后保留，清空宏并恢复改键后复原。支持按键按下/松开、组合、鼠标左中右键和等待时间；播放方式支持一次、N 次、再按停止、按住重复（后两种未实机验证），驱动的“点按播放”未开放。宏要在改键里绑定为 `macro:N` 才会播放。键盘不提供读取，每次写入替换全部宏；`ak35i macro clear --apply` 清空。在控制中心“宏”页或 CLI `ak35i macro set` 写入。 |
| 2.4G 控制 | 实验性 | 键盘在 2.4G 下接受驱动的 32 字节短包（见静态逆向记录「2.4G 与蓝牙」）。已支持并实机验证：时钟同步、电量读取、基础灯效（`05`）、系统设置（`07`）、改键两层（`10` / `12`）、宏（`09`，宏表最多 3,024 字节）、单键颜色（`14`，读不回）、音乐律动（`0B` 柱状图，固定配色；其它实时效果需要数据线）、屏幕上传（`7F` + `80–8F`，Windows 驱动的 2.4G 菜单没有开放，单帧约 2,300 包、约 1 分钟，丢包时同一包最多重发 3 次）。2.4G 下读不回单键颜色。其余功能逐项移植，暂时需要数据线。 |
| 蓝牙控制 | 不支持（仅电量） | 蓝牙下键盘没有厂商 HID 报告；V1.17 固件在蓝牙模式下丢弃厂商命令（`0x5B54`），Windows 驱动也没有蓝牙设置路径。唯一的厂商 GATT 服务 `FEE0` 试写一次在线探测没有回应。设置用 2.4G 或数据线写入后，切回蓝牙仍保留。 |
| 固件版本显示 | 已验证（只读） | 有线取 USB 设备版本号，2.4G 取在线探测的信息块，两者实测都是 V1.30；蓝牙下只能显示蓝牙模块版本。见 `ak35i status` 或概览页。 |
| 配置导出 / 导入 | 未实现（计划） | 键盘读不回改键、宏、系统设置和灯效，控制中心也不保存，重开后无法知道或恢复上次写入的内容。计划把这些设置连同上传屏幕时用的原图存成 Mac 上的文件，用于恢复和迁移。 |

## 数据存放位置

键盘里（断电保留）：

- 改键（两层）、灯效、宏、系统设置、单键颜色都存在键盘里，拔插后保留，已实测。具体在主控芯片的内部闪存还是外置闪存，尚未确认。除单键颜色可用 `04 F5` 读回外，本项目不读回这几项。
- 屏幕 GIF 页在外置闪存 `0x950000` 起，出厂开机动画在 `0x340000`，上传不会覆盖开机动画。USB 协议没有读外置闪存的命令，上传后读不回。地址来自固件 V1.17 静态分析，实测行为与之一致。

Mac 上：

- 不保存任何键盘配置。各页面里编辑的改键表、宏、系统设置和灯效参数只在内存中，退出即丢失；重开后这些页面显示默认值，不反映键盘当前状态。“单键灯光”页例外，它每次先读键盘。
- 选来上传的图片留在原位置，程序只读取并在内存中转换，不复制。
- 程序会写到 Mac 的文件只有：
  - `~/Library/Preferences/dev.ak35i.controlcenter.plist`：macOS 自动记录的界面状态，例如文件选择器上次打开的目录；
  - 开启自动校时后的 `~/Library/LaunchAgents/dev.ak35i.controlcenter.clock-sync.plist` 和日志 `~/Library/Logs/AK35iClockSync.log`；
  - CLI `--preview` 指定路径的预览 PNG。

解锁一个功能需要四类证据：单项操作对应的报文、设备应答、断线重连后的持久化，以及可恢复基线。证据可以来自 Windows 抓包，也可以来自 macOS 实机试验，前提是写错后有可恢复路径：键盘快捷键、读回后写回，或已知的默认值。静态逆向只能缩小范围，不能替代真机验证。详细记录见 [静态逆向记录](STATIC_REVERSING.md)。
