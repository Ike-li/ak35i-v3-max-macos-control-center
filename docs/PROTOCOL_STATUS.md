# 功能与协议状态

此参考页说明每项功能的可用状态，不代表厂商公开规格。

| 功能 | 状态 | 依据与边界 |
|---|---|---|
| USB 设备发现 | 已验证 | VID:PID `0C45:8009`；仅匹配厂商 HID collection，避免访问普通键盘输入接口。 |
| 屏幕时钟同步 | 已验证 | 64-byte Feature 载荷；UTC+8 与 Mac 当前时区均可选。 |
| 屏幕数据通道发现 | 已验证 | `0xFF68:0x0061`，Output 4 KiB；不代表已验证图片/GIF 格式。 |
| 电量读取 | 锁定 | 读取命令与语义尚未通过 V3 Max 抓包验证。 |
| 基础灯效 | 实验性 | `04 13` 序列：20 种模式及亮度、速度、方向、颜色。模式 1 静态色已在 macOS 实机验证（设备确认、效果正确、重连后保留），模式 16 川流不息目测正常；其余模式沿用同一命令，模式号和参数取值来自 Windows 驱动静态分析，效果待逐一确认。在控制中心“灯光”页或 CLI `ak35i light set` 写入，可用 `Fn+\\|` 等快捷键恢复。 |
| 用户灯效、自定义单键颜色、音乐律动 | 锁定 | 命令已在静态分析中定位，尚无实机证据。 |
| 图片/GIF 上传 | 锁定 | 传输通道已见，但编码、提交序列和回滚均未验证。 |
| 板载改键 / Fn 层 | 锁定 | 需要读取、写入、持久化与回滚的完整证据。 |
| 宏 | 锁定 | 事件编码、延时和持久化序列尚未验证。 |
| 蓝牙 / 2.4G 控制 | 不承诺 | 当前发布仅支持 USB 有线控制。 |

解锁一个功能需要四类证据：单项操作对应的报文、设备应答、断线重连后的持久化，以及可恢复基线。证据可以来自 Windows 抓包，也可以来自 macOS 实机试验，前提是写错后能用键盘快捷键恢复。静态逆向只能缩小范围，不能替代真机验证。详细记录见 [静态逆向记录](STATIC_REVERSING.md)。
